SAMSUNG PHONE UPLOAD — NO FOLDERS NEEDED

1. Extract My_Digital_Library_Phone_Upload.zip in Samsung My Files.
2. Open the extracted folder and select ALL its files.
3. GitHub repository > Add file > Upload files > Choose your files.
4. Upload every file directly beside index.html. The updated index.html, app.mjs and sw.js REPLACE your previous copies. Commit changes.
5. Keep pdf-resources.zip AS A ZIP and upload it with the other files. Do not extract it: the app reads it automatically.
6. Open your GitHub Pages URL in iPad Safari. Refresh the page, then Share > Add to Home Screen.
7. Open the Home Screen app while online and wait for Offline ready. Import a book and test reopening with Wi-Fi off.

The icon.png file is your Home Screen icon and is included. No vendor folder is needed in this version. Your imported books and notes stay on your device. Back up library regularly to Files.

PDF and EPUB supported; PPTX has a basic text/image viewer. Convert older PPT files to PDF. Scanned PDFs need drawn highlights. EPUB handwriting uses a chapter note sheet. PDF font and character resources are served offline from pdf-resources.zip by the service worker; HTTPS hosting is required. Opening index.html directly from Files does not install offline reading.
