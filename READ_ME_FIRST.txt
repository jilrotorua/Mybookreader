MY DIGITAL LIBRARY — IPAD SETUP

The ZIP includes the full app, offline reading dependencies and icon.png for your Home Screen.

1. Download this ZIP and extract it in Files or on your computer.
2. Upload ALL extracted files and the vendor folder to the root of a GitHub Pages repository. Keep the folder structure exactly as supplied. The index.html file must be at the root, not inside an extra folder.
3. Enable GitHub Pages: repository Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Open your GitHub Pages link in Safari on your iPad while connected to the internet.
5. Tap Share > Add to Home Screen. The included book icon appears automatically.
6. Open the Home Screen icon while online and wait for “Offline ready”.
7. Tap Add books and choose PDFs, EPUBs or PPTX files from Files.
8. Switch off Wi-Fi and check that the app reopens and your imported book still reads.

IMPORTANT: Opening index.html directly from the ZIP or Files will not install a reliable offline app. It needs an HTTPS website such as GitHub Pages for initial setup.

Your books and notes stay on the iPad; they are not uploaded to GitHub. Only the app files are hosted. Keep using the same website and Home Screen icon. Use Back up library regularly and save its ZIP in Files. Clearing Safari website data may remove books and notes. A different website address has a separate local library.

PDF and unprotected EPUB reading are supported. PPTX has a basic text/image viewer; exact slide layouts, charts, animations and themes are not guaranteed. Older PPT files should be exported to PDF first. Scanned PDFs can be marked with the drawing highlighter but do not have selectable/searchable text. EPUB handwriting uses the chapter note sheet. Typed notes export separately from annotated PDFs. Rotated PDF page export is not supported.

The included software dependencies are distributed with their license files in vendor.
