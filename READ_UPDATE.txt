UPDATE YOUR EXISTING GITHUB REPOSITORY

1. Use Back up library in your iPad app and save the backup ZIP in Files.
2. Extract this update ZIP on Samsung.
3. Upload index.html, style.css, app.mjs and sw.js to the SAME repository and SAME folder as your existing index.html. Replace the old copies. Commit changes.
4. Keep the other existing app files, icon and pdf-resources.zip in place.
5. Once GitHub Pages finishes updating, open the app while online. Close and reopen once so the new offline cache can take control. Wait for Offline ready.

The update keeps the same local database and your books, notes and collections. Do not clear Safari website data, use a new website address, or delete your books.

PDF pages now appear consecutively. Use Scroll and swipe up to continue. Select Pen or Mark to annotate the current page; switch back to Scroll to move through the document. More contains search, themes and export tools.

Collection, title and note dialogs now focus the text field and include a Type keyboard button. If an iPad still hides the software keyboard because a physical keyboard is connected, use the iPad keyboard control to show the onscreen keyboard. Browser code cannot override that hardware setting.
