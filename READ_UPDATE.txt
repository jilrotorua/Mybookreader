Back up your library first. Replace these four app files in your existing GitHub repository; keep the other files. Reopen while online. Do not clear website data.

New collection now uses the browser text-entry prompt. Book details: tap Edit title, type into the prompt, tap OK, then Save changes.

The four built-in collections are removed once on update. Books previously in those collections become Unfiled; books and notes are kept. Your other custom collections stay. You can create any collection name, including a former preset, after the update.

The browser cannot force the onscreen keyboard if iPadOS is using a connected physical keyboard. If needed, disconnect it or use iPadOS Show Keyboard.
